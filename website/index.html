What is included

A starter that behaves like a real project.

01

Single-purpose agent

EmailAgent focuses on sending clear, structured email notifications through a tool call.

02

External API tool

The Resend integration shows how ADK agents can safely call provider APIs and return useful results.

03

Configurable model

Nebius model, API key, and base URL are controlled through environment variables.

04

Testable behavior

Pytest coverage mocks email delivery so the tool can be checked without sending real messages.

Run it locally

Install, configure, and start the ADK agent.

pip install -r requirements.txt
cp .env.example .env

adk run email_adk_agent

# Or open the ADK development UI
adk web
